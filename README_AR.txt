موقع مرسي للأنظمة الأمنية — خطوات التشغيل والنشر

الملفات:
- index.html: الصفحة الرئيسية للموقع.
- robots.txt: يوضح لمحركات البحث أن صفحات الموقع مسموح بفهرستها.
- sitemap.xml: خريطة أولية للموقع.

تجربة الموقع على الكمبيوتر:
1. فك ضغط الملف ZIP.
2. افتح المجلد.
3. افتح index.html في المتصفح، أو افتح المجلد في VS Code واستخدم إضافة Live Server.

مهم قبل النشر:
- اسم النطاق morsi-security.com مقترح فقط؛ لم يتم شراؤه أو التحقق من توفره.
- لا تستخدم عنوان النطاق الفعلي قبل حجزه وربطه بالاستضافة. حدّث canonical وog:url وurl داخل JSON-LD وملف sitemap.xml إذا اخترت نطاقًا آخر.
- راجع النصوص والخدمات وأكد أنها تمثل خدماتك بالفعل. أضف صورًا حقيقية من شغلك، ولا تضع تقييمات أو عناوين غير مؤكدة.
- الموقع لا يحتوي على لوحة إدارة أو قاعدة بيانات؛ هو موقع تعريفي ثابت.

نشر مجاني مبدئي باستخدام GitHub Pages:
1. أنشئ حسابًا في GitHub.
2. أنشئ مستودعًا عامًا جديدًا (Public repository).
3. ارفع الملفات الثلاثة إلى جذر المستودع.
4. من Settings ثم Pages، اختر النشر من الفرع الرئيسي (main) ومجلد /(root)، ثم احفظ.
5. اختبر رابط GitHub Pages الذي سيظهر لك.
6. إذا اشتريت النطاق الخاص، أضفه في إعدادات Pages أولًا ثم اضبط سجلات DNS المطلوبة لدى شركة النطاق، واتبع إرشادات GitHub الرسمية:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

إظهاره في Google:
1. بعد نشر الموقع على عنوان يعمل عبر HTTPS، افتح:
https://search.google.com/search-console/about
2. أضف الموقع كـ URL-prefix أو Domain property، وأكمل التحقق من الملكية.
3. من قسم Sitemaps أرسل: sitemap.xml
4. استخدم URL Inspection لفحص الصفحة الرئيسية وطلب الفهرسة.
5. أنشئ/حدّث ملف Google Business Profile إذا كان نشاطك مؤهلًا، واستخدم اسم النشاط الحقيقي ومعلومات الاتصال الصحيحة.
6. لا يوجد ضمان لظهور فوري أو ترتيب معين. تجنّب حشو الكلمات المفتاحية؛ أضف محتوى أصليًا وصورًا حقيقية ومعلومات دقيقة.
